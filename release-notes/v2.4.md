## Fix: Moonlight games wouldn't start

Starting a game from a Moonlight category could show *"missing emulator find rules configuration for 'MOONLIGHT'"*.

- Moonlight categories now open Moonlight directly, the same way ES-DE opens Android apps, so they no longer depend on an emulator rule in `es_find_rules.xml`.
- Categories made with an older version are fixed automatically the next time you open ES-DE Commander. The old rule is removed.
- If you use the root build of Moonlight, pick *Moonlight (root build)* as the category's alternative emulator in ES-DE.

After updating: open ES-DE Commander once, then close ES-DE completely and start it again.
