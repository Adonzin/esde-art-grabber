**Theme copies: safer downloads, checking and clean-up**

- Theme downloads are now verified. Before, a download cut off part-way (for example by a Wi-Fi drop) could silently produce a copy with files missing, so some systems lost their pictures. Now the size and the zip's own index are checked, every file is checked after saving, and a cut-off download stops with a clear message instead. Your existing copy stays as it was.
- **Check copy** (Themes screen) lists any of your systems that have no carousel image in the copy, and tells you whether a refresh should fix it.
- Each copy now shows how much space it takes, next to its **Delete** button.
- **Leftovers:** unfinished folders from interrupted downloads are listed and can be cleaned up in one tap.

If a copy you made with 2.1 or 2.2 is missing pictures, tap **Refresh copy**.
